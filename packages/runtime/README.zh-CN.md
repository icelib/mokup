# @mokup/runtime

[English](./README.md) | 中文

## 概览

Mokup runtime 用于在请求时读取 manifest 并返回 mock 响应，是 Server 适配器与 Worker 的共享核心。完整文档见 https://mokup.icebreaker.top。

## 环境要求

- Node.js `>=22.12.0`

## 升级提示

- 该包现在只提供 ESM 输出。
