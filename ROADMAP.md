# M0–M2 implementation and acceptance

The target remains a file-first, cross-runtime, contract-aware API mocking platform.
This file tracks the complete requested scope. An implemented feature is not an accepted
milestone until its release gates have been verified. Existing file routes, Hono handlers,
published Node 20 support, and Vite 5–8 support remain requirements.

## Verified checkpoint: 2026-10-06

The shared adapter checkpoint includes mounted Hono sessions, dynamic parent scopes,
original URLs and context, response cookies, mounted refresh/cancellation, deliberate
404 versus downstream fallthrough, manifest metadata snapshots, and Webpack paused
file snapshots. The deployed-session E2E file is registered in the default suite.
Conformance and root E2E artifacts use separate directories; lint excludes generated
Playwright output.

- Unit suites: 276 passed files and one skipped; 2,029 passed tests, one skipped and one todo.
- Coverage: 87.41% statements, 79.91% branches, 88.75% functions and 87.58% lines.
- App E2E: all nine executed app suites passed, totaling 45 tests across Vite, Webpack, Node, Worker, Cloudflare/D1, docs and Playground flows.
- Browser conformance: 45 passed across Chrome, Firefox and WebKit, covering both interceptor and Service Worker modes, including EventSource and WebSocket lifecycle/message interception.
- Packed Node consumers: Node 24.18.0 passed the runtime compatibility suite, including mounted sessions, external handlers, middleware, HTTP bodies, cookies, binary requests, WebSocket metrics and cancellation.
- Packed Vite consumers: 5.0.0, 5.4.21, 6.0.0, 6.4.1, 7.0.0, 7.3.6, 8.0.0 and 8.3.2 passed.
- Type checks: 27 workspace tasks passed; `@mokup/msw` public `tsd` types and MSW 3.0.2 dev fixtures passed after the resolver and response-body alias audit.
- Lint and docs build passed. Migration and line guards passed; the line guard still reports four existing files above 300 lines.

This is checkpoint evidence, not milestone acceptance. Native file authoring,
structural adapters, MSW handler-object/generator/once parity and callback policies
are implemented and covered by tests. M0 still requires the complete transport
behavior matrix and final boundary/event audits before it can be accepted. The
OpenAPI YAML/reference loader, security and multipart contract bridge, GraphQL source
generation, persisted-operation maps, SSE and graphql-transport-ws subscriptions, finite
recording proxy and streamed Playground diagnostics are now implemented; parameter
serialization, transparent streaming capture, CLI fixture parameter validation, runnable
deployment templates, and optional Devframe/MCP bridges are now implemented. MCP
generation also has a tested generate-to-validate fixture loop and a versioned
structured-content contract for review panels. Provider matrix smoke tests now run
in CI; richer MCP host wiring, integrated coverage controls, and the complete plugin
ecosystem remain open. HTTP
matcher decision chains and actionable Playground miss explanations are implemented for
the shared session and streamed server diagnostics; GraphQL/SSE/WebSocket miss handling now
shares the deferred policy path, while protocol-wide payload parity remains open. The MSW
facade now exposes lifecycle listeners with MSW-shaped request/response metadata. Team
package distribution uses Git/npm as selected by the user; no independent registry is
planned, while package contract, validation and policy examples remain. Deployment-template
and packed Mock-package contract checks now run in CI. `compareLive` now
provides the reusable bounded mock-versus-real comparison primitive; scheduled execution
and provider wiring remain open.
